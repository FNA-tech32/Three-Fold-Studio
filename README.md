# Three Fold Studio

> **Sustainability insights, built for business.**  
> Track impact, reduce emissions, and accelerate progress—with clarity and confidence.

---

## 🌿 Overview

**Three Fold Studio** is an enterprise sustainability intelligence platform designed to help organizations measure, model, and act on their environmental impact. By connecting real-time operational data with actionable decarbonization pathways, Three Fold Studio equips business leaders with the clarity needed to make audit-ready, impactful climate decisions.

---

## ✨ Key Features

- **Track (Granular Emissions Monitoring)**  
  Aggregate carbon footprints, supply chain emissions, and energy consumption across global operations in real time.

- **Model (Predictive Climate Scenarios)**  
  Simulate decarbonization pathways and forecast financial and environmental outcomes before allocating capital.

- **Report (Automated ESG Compliance)**  
  Generate audit-ready disclosure reports aligned with global reporting frameworks (CSRD, GHG Protocol, SEC, CDP).

- **Act (Operational Decarbonization)**  
  Convert intelligence into concrete business initiatives that lower overhead, optimize resource usage, and reach net-zero milestones.

- **Responsive & Modern Design**  
  Crafted using semantic HTML5 and modern Tailwind CSS, ensuring smooth rendering across desktop, tablet, and mobile displays.

- **Direct & Alternative Contact System**  
  Equipped with primary and alternative communication channels for inquiries, customer support, and enterprise emergency SLAs.

## 🚀 Getting Started

### 1. View in Browser
Simply open `index.html` in any modern web browser:
```bash
# Windows
start index.html

# macOS
open index.html

# Linux
xdg-open index.html
```

### 2. Run with a Local Development Server
To test smooth scrolling and local server asset delivery, you can use any static server:

**Using Node.js:**
```bash
npx serve .
```

**Using Python 3:**
```bash
python -m http.server 8080
```

Then visit [http://localhost:8080](http://localhost:8080) in your browser.
